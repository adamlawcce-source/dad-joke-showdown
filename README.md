A tiny Node 22 program for the make.fun bounty
[Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5).

`main.ts` writes one dad joke to `/output/entry.txt`: a father tells his
kids he quit baking because he couldn't make enough dough, so now he just
loafs around the house telling jokes. Two puns on the same beat — "dough"
and "loaf" — with the punchline at the end. No network, no randomness, no
input — the same line on every run.

Run it with Node 22:

```sh
node main.ts
```
